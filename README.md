# Warehouse Robot COA Project

## Overview
This project demonstrates a warehouse robot simulation integrated with a 16-bit CPU using Logisim Evolution.

## Features
- 16-bit CPU architecture
- Program counter, control unit, register file and ALU
- Robot movement on an 8×8 grid
- Coordinate-based pickup detection
- Robot position visualization using an 8×8 dot-matrix display

## Tools Used
- Logisim Evolution
- Digital logic circuits and CPU architecture

## How to Run
1. Download or clone this repository.
2. Open the main `.circ` file in Logisim Evolution.
3. Ensure all supporting circuit libraries are available and correctly linked.
4. Load the required instruction program and run the simulation.

## Project Status
An educational circuit-level simulation. Refer to the project report for implementation details and verified test results.
